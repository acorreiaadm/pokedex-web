# ⚡ Pokédex Web Application

Aplicação web interativa desenvolvida com foco em boas práticas de desenvolvimento front-end e gestão ágil de projetos. O projeto simula uma enciclopédia digital de Pokémon, priorizando a experiência do usuário (UX), a clareza na interface e a organização estrutural do código.

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido de forma colaborativa utilizando metodologias ágeis (**Scrum**)[cite: 4]. A aplicação consome dados para exibir informações detalhadas sobre os Pokémon de forma dinâmica, responsiva e otimizada para diferentes dispositivos.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Front-End:** HTML5, CSS3, JavaScript (ES6+)
* **Metodologia Ágil:** Scrum[cite: 4] (Sprint Planning, Gestão de Tarefas)
* **Gestão de Projeto & Tarefas:** Trello[cite: 4]
* **Modelagem e Requisitos:** Diagramas de Casos de Uso (UML) e Wireframes de baixa/alta fidelidade[cite: 4]
* **Versionamento:** Git e GitHub

---

## 📋 Etapas de Desenvolvimento & Engenharia de Software
Diferente de uma simples implementação visual, este projeto passou por um ciclo completo de engenharia de software:
1. **Levantamento de Requisitos:** Mapeamento detalhado das funcionalidades essenciais e regras de negócio da aplicação[cite: 4].
2. **Modelagem UML:** Criação de diagramas de casos de uso para estruturar o comportamento do sistema[cite: 4].
3. **Prototipagem:** Elaboração de wireframes de baixa fidelidade para definir a disposição dos elementos visuais na interface[cite: 4].
4. **Sprint & Gestão:** Acompanhamento de entregas e distribuição de tarefas da equipe através do Trello[cite: 4].

---

## 🎯 Funcionalidades Principais
* Listagem dinâmica de Pokémon.
* Interface totalmente responsiva para desktop e dispositivos móveis.
* Navegação fluida e estruturação lógica limpa baseada em componentes orientados a eventos.
